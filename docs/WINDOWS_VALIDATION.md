## 비문서 Explorer 연동의 한계

`windows/runner/platform/desktop_shell.cpp`만 Progman 0x052C 요청과 WorkerW/SHELLDLL_DefView 탐색을 담당합니다. 다른 코드는 이 계층을 알지 않습니다. SetParent와 반환값, 부모 핸들 확인은 **Win+D 동작 성공을 증명하지 않습니다**.

네이티브 호스트는 TaskbarCreated 메시지와 2초 타이머로 연결 상태를 확인하고 재연결 또는 일반 창 전환을 시도합니다. Explorer가 자식 HWND까지 파괴하는 Windows 구성에서는 현재 코드가 Flutter 창을 새로 생성해 복구하는 경로를 제공하지 않습니다. 따라서 **Explorer 재시작 복구와 저장 전 입력 보존은 미완료/미검증**입니다. 검증 전에 바탕화면 모드를 안정 기능으로 간주하면 안 됩니다. 일반 창 모드의 데이터 저장 테스트와 이 위험을 구분합니다.

투명 합성은 `window_manager` 0.5.1에 격리되어 있으며 이 패키지 역시 일부 비문서 Windows 합성 API를 사용합니다. UI·모델·Repository는 해당 API에 의존하지 않습니다. Windows 버전별 합성과 DPI 호환성을 검증해야 합니다.
